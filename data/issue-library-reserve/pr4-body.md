## 既有环境性失败（与本次改动无关）

**`src/utils/ios_deep_link_scheme_patch.spec.ts`** —— `SyntaxError: Invalid or unexpected token`，
0 test 收集，发生在模块 transform 阶段。

已定位根因并给出证据：

```
$ git ls-files --eol apps/client/scripts/patch_ios_deep_link_scheme.mjs
i/lf    w/crlf  attr/
```

**索引是 LF、工作区是 CRLF** —— Windows 检出把 shebang 行弄成了 `\r\n`，导致解析失败。
对照实验：该 `.mjs` 去掉首行 shebang 或转成 LF 后即通过；同目录无 shebang 的 `prepare_dist.mjs` 导入正常。
**CI 在 Linux 检出为 LF，故不复现。** 属既有环境问题（该 spec 与脚本本次均未改动）。

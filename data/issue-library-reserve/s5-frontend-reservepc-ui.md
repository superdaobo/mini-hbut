## TL;DR

实现静音仓与研讨室的预约流程 UI（资源列表 → 选时段 → 填表 → 提交 → 我的预约 → 取消），
这是本次**第一个可交付给用户的完整功能**。

## 需求描述

用户应能在 App 内完成静音仓/研讨室的全链路预约，不必跳转微信或超星 App。

## 当前行为

前端无任何图书馆预约界面。

## 期望行为

- 列出静音仓 / 研讨室及其开放时间、地点、容纳人数
- 选择日期与时段（受 `advanceDays` 与开放时段约束）
- 按 `customFormConfig` 动态渲染并校验预约表单
- 提交前二次确认，并展示违约规则提示
- 可查看"我的预约"并取消

## 已知事实（勘察产出）

### 资源清单（实测）

- **静音仓**：1–5 号，图书馆四楼，08:00–21:30，容纳 2–6 人
  （官方提示：要求 2–6 人使用，1 人使用需到图书馆 2 楼服务台咨询）
- **研讨室**：1–7 号，图书馆 4 楼 D 区，08:00–21:00，容纳 2–8 人（7 号为 6–30 人）

### 约束（来自 `reserve/info` 实测）

| 字段 | 值 | 含义 |
| --- | --- | --- |
| `advanceDays` | 3 | 可提前 3 天预约 |
| `advanceTime` | `00:00` | 放号时间 |
| `durationLimitMin` | 241 | 单次最长 241 分钟 |
| `confirmDialog` | 1 | 需弹确认框 |
| `dialogTitle` / `dialogContent` | 特别提醒 / HTML | 首次进入的提醒内容 |
| `cancelLimit` | -1.0 | 取消限制（-1 表示不限） |

### 动态表单

`reserve/item/list/time` 返回的 `customFormConfig` 是**表单定义 JSON 字符串**，
含字段类型、校验规则、默认值、关联绑定（`bindFormField`）、选项等。
提交体需要与该配置对应。

> ⚠️ `customFormConfig` 与提交体的**映射关系尚未抓全**，需在开放时段走一遍真实预约补齐（见 S2 待补齐项）。

## 影响范围

涉及模块：前端图书馆预约视图组件与其子组件（依赖 S4 建立的容器）

## 验收标准

- [ ] 静音仓与研讨室列表正确展示（名称 / 开放时间 / 地点 / 容纳人数）
- [ ] 可查看可预约时段，不可约时段有明确视觉区分
- [ ] 表单按 `customFormConfig` 动态渲染，必填与格式校验生效
- [ ] 提交前有二次确认，并明确提示违约后果（未签到记违约 / 7 天内 3 次停用 3 天）
- [ ] 提交成功后有明确反馈，并刷新"我的预约"
- [ ] 可取消预约，取消前二次确认
- [ ] 提交失败时区分业务失败（时段被占 / 超限 / 停用）与网络失败，给出可读文案
- [ ] 加载中 / 空态 / 错误态齐备
- [ ] i18n 三语齐备
- [ ] `npm run typecheck` 通过

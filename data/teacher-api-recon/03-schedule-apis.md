# 课表域接口文档（教师端 · 只读）

> **本文档只收录「已确认只读」的接口。**
> 数据来源仅限本次勘察已落盘的三个文件：
> `01-pages-and-paths.md`、`07-write-endpoints-denylist.md`、`08-probe-results-raw.md`。
> **所有写型 / 导出 / 打印 / 产物型接口均不在本文档内**，它们已登记在 `07-write-endpoints-denylist.md`
> 的 A/B/C 类清单中，接入时一律禁止调用。
>
> 勘察环境：账号 `教师 <教师工号>`，`currentRoleId=js`，学期 `2026-2027-1`，探测时间 `2026-10-09`。
> 全部样本均为 **GET 只读请求**的实测结果，未调用任何写型接口。
>
> **凡本文档未标注「实测」的字段含义，均为按命名缩写推断，接入前需以真实响应复核。**
> 不得据本文档臆造字段或行为。

## 0. 通用约定（所有接口共享）

以下约定摘自 `08` 文件第 I 节，适用于课表域全部接口。

| 约定 | 内容 |
| --- | --- |
| 请求方法 | 全部为 **GET**（课表域无已确认的查询型 POST） |
| 列表包裹形态 | jqGrid 风格：`{msg, ret, page, rows, total, totalPages, results[]}` |
| 下拉/字典包裹形态 | 裸数组 `[…]` |
| 设置类包裹形态 | `{ret, msg, extend}` 或 `{ret, msg, data}` |
| 身份字段注入 | 绝大多数响应**每条记录**被注入 `currentUserId, userRoleId, dataAuth, dataXnxq, currentRoleId, currentJsId, currentUserName, currentDepartmentId`，末尾还有 `new`（布尔）。**解析时应全部忽略** |
| 分页参数 | `page`、`rows`、`gridtype=jqgrid`、`_search=false`、`sort`、`order` |
| `encodeId=1` | 让响应额外带 `encodeId` 字段（前端用于二次跳转），可安全使用 |
| 错误形态 1 | `{ret:-1,msg:"参数传输异常" / "数据传输异常" / "关键参数缺失"}` → 缺参数 |
| 错误形态 2 | `{ret:-1,msg:"没有访问当前接口的权限!Subject does not have permission [模块:子模块]"}` + **HTTP 401** → 无权限 |
| 错误形态 3 | HTTP 404 / 500 + 页面「无法访问」→ 路径不存在或需其它 HTTP 方法 |
| 错误形态 4 | HTTP 200 + 页面「报错啦 / 错误原因：…」→ 业务错误页 |

### 2.4 实测结果

| 项 | 值 |
| --- | --- |
| HTTP 状态 | 200 |
| 响应结构 | `{ret:0, msg:"操作成功", data:[…]}`（**裸数组，无分页包裹**） |
| 是否需参数 | 是（`xnxq` + `id`） |
| 返回条数 | 2026-2027-1 = 4；2025-2026-1 = 8；2025-2026-2 = 20（**均为按小节逐行的原始行数**） |

#### 三个学期 `(djc/djs)` 组合交叉验证

| 学期 | 出现的 `(djc/djs)` 组合 | 原始行数 |
| --- | --- | --- |
| 2026-2027-1 | `7/4`、`8/4` | 4 |
| 2025-2026-1 | `1/1`、`2/1`、`3/2`、`4/2` | 8 |
| 2025-2026-2 | `1/1`、`2/1`、`3/2`、`4/2`、`5/3`、`6/3`、`7/4`、`8/4` | 20 |

→ `djs = ceil(djc/2)` 三学期全部自洽；按「连堂数」解释会得出跨大节重叠的矛盾结果。

#### 去重示例（2026-2027-1 同一门课的 4 行 → 2 张卡片）

| 原始行 | `djc` | `djs` | `zc`/`zcstr` | `zctype` | `croombh` |
| --- | --- | --- | --- | --- | --- |
| 1 | 7 | 4 | `7` / `7` | `1`（单周） | `2-209` |
| 2 | 8 | 4 | `7` / `7` | `1` | `2-209` |
| 3 | 7 | 4 | `8-14` / `8,9,…,14` | `0`（全周） | `5B-704` |
| 4 | 8 | 4 | `8-14` / `8,9,…,14` | `0` | `5B-704` |

→ 去重后：
1. 星期一 大节 4（小节 7-8），第 7 周（单周），`2-209`（2号）
2. 星期一 大节 4（小节 7-8），第 8-14 周，`5B-704`（5号）

**聚合键建议**：`(课程 + 教学班 + 课程名 + 星期 + 周次 + 教室 + 周类型 + 大节)`；
聚合后取**小节区间**（`min(djc)` … `max(djc)`）作为起始节与连堂数。

### 2.5 注意事项（已知结论）

1. **`id` 是服务端加密的 teacherId。**
   只能从 `/admin/pkgl/pkgljskb/queryKbForJsd` 页面隐藏域 `#teacherId` 抓取，
   **不存在客户端生成算法**；不要尝试用工号或 `currentJsId` 直接拼装。
   （`01`/`08` 未记录该加密值本身，也无法确认它与 `currentJsId` 是否相等。）

2. **`djs` 是大节号 = `ceil(djc / 2)`，不是连堂数。**
   `djc` 为小节号（该字段名来自勘察结论）。即：小节 1、2 → 大节 1；小节 3、4 → 大节 2，以此类推。

3. **接口按「小节」逐行返回。**
   一门课若跨越多个小节/大节，会返回多行；**跨大节会返回 2 行，客户端必须去重**。

4. 每条记录都会被注入身份字段与 `new`，解析时应忽略（见第 0 节）。

## 附录 B. 数据矛盾与缺口（本次汇总）

### B.1 缺口（缺字段/缺数据）

1. **`getJskbByXqid` 无字段级样本** —— 课表域**最核心**接口，`08` 文件 H 节却未收录其字段清单，

2. `getJxlList`（教学楼，35 条）、`getXnxqByJcxx`（11 条）、`getZcbzbyxq`（1 条）、
   `selectJxzxsj`（11 条）**均无字段级样本**，字段名未知。

   只能从来源页面隐藏域抓取。

### B.2 矛盾 / 不一致

1. **07 文件 D 类清单与 08 实测清单不一致**：
   `getJxbzcxq`、`ajaxJskbList`、`getXnxqByJcxx` 在 08 中已实测为只读 GET（返回错误体但无副作用），
   但**未出现在 07 的 D 类清单**里。本文档按任务要求收录了它们。

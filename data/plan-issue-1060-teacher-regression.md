## 3. 静态审计已确认的根因（各 agent 的修复锚点）

1. **#1064 详情底色**：`TModal.vue:5` 容器用 `glass-card`，无组件级不透明底；`style.css:12` `--ui-surface` = `rgba(255,255,255,0.9)`（alpha=0.9）→ 二级详情透出底层列表。
2. **#1062 空教室语义**：`schedule.rs:663-808` 教师分支只发 jqGrid 保守列表请求（`getZyKjs`），**不应用周次/节次**，却返回 `filters_applied=false`；`ClassroomView.vue:132-180` 又用本机 `hbu_schedule_meta` 周次覆盖展示 → 「未知日期 + 第7周」自相矛盾。
3. **#1063 误报风险**：`schedule.rs:804` 附近把返回教室直接标 `status: "可用"`；`data/teacher-api-recon/03-schedule-apis.md` §6 证实 `getZyKjs` **只有教室资源目录，无任何时间维度占用证据**（191 条）。
4. **#1061 切号**：Rust `switch_active_account` 只做本地 Cookie 注入（`application/auth.rs:259-338`，注释明写「不发网络登录」）；前端 `AuthCoordinator.ts:381-456` 在验证完成前就切 role 并进首页，失败仅落 `cached_offline` + 轮询。
5. **#1065 缓存位置错**：`useTeacherTeaching.ts:121-176`、`useTeacherExams.ts:156-209` 的 `Map` 建在 composable 函数内部，每次挂载重建 → 跨页失效。
6. **#1066 无同步时间**：教师各 view 模板未渲染任何 `lastUpdatedAt` / `lastSuccessfulSyncAt`。
7. **#1067 串行请求**：`teacher/teaching.rs:258-283` 两个独立只读 GET 串行；`teacher/exams.rs:240-262` 同样；`teacherApi.ts:110-145` 无 in-flight 去重。

## 4. 关键约束（贯穿所有改动）

- **安全**：只读；缓存按 `role + accountId + semester + filter` 隔离；严禁 Cookie/密码进 localStorage / Issue / 日志。
- **诚实性**：禁止伪造 200 成功、禁止凭空填充状态、禁止把无证据的教室标为「空闲」。
- **不回归**：学生端功能、学生缓存、学生成绩弹窗、课表全部不得回归。
- **门禁**：`ci.yml` PR Gate 必须全绿 ——
  - frontend：`npm run build`、`npm run test:ci`、`check-frontend-safety.mjs`、`check-design-tokens.mjs`、`check_arch_guards.mjs`、`vue-tsc --noEmit`、`typecheck:js-sfc`
  - rust：`cargo test --lib`、`cargo fmt --all -- --check`、`cargo clippy --lib`、keyring 后端断言
  - `secret-guard` 按 **commit range** 扫描敏感内容（凭据绝不入库）
- **i18n**：教师文件不在 `i18n_coverage.spec.ts` 白名单内（硬编码中文不阻塞 CI），但 #1066 明确要求中/英/日三语，故新文案走 i18n key。

## 5. 真实测试策略（不靠单测冒充真机验证）

issue #1068 明确：**不得以「已 merge / 单测通过」代替真机验证**。本机（Windows）可执行的证据链：

1. **静态门禁**：全量 vitest + vue-tsc + js-sfc + cargo test/fmt/clippy + `npm run build`。
2. **真实账号只读接口验证**（本机网络可达学校时）：
   用 `HbutClient` 真实登录，验证教师登录、教学任务/教学班、监考/考试、空教室查询的真实返回与语义；结论脱敏后落 `data/teacher-api-recon/`。
3. **真机级 UI 验证（Windows 桌面 dev 构建 + Debug Bridge）**：
   应用在 debug 构建下默认启用 `http://127.0.0.1:4399` 的 Debug Bridge，可用：
   - `POST /debug/navigate` 切换视图
   - `POST /debug/frontend-eval` 在页面内执行 JS（读取渲染结果、`getComputedStyle` 断言、触发交互）
   - `POST /debug/screenshot` / `dom_screenshot` 取证
   - `GET /debug/logs` / `GET /debug/diag` 读取运行时日志与会话诊断
   用于验证：详情弹层不透明（computed alpha==1）、空教室语义与日期周次一致、切号后在线状态、缓存与「上次同步」栏、请求次数与耗时。
4. **iOS/Android**：本机无法执行，**如实列为未验证项**，不虚报通过。

## 6. 风险与回滚

| 风险 | 缓解 |
| --- | --- |
| 学校不支持时间维度筛选 | 降级为「教室资源列表（非实时空闲）」，隐藏无效节次筛选，**绝不**标「可用」 |

| 并发改造触发学校限频/反爬 | 保留串行回退开关 |
| 切号失败导致锁死 | fail-closed：明确要求目标账号重新登录，绝不静默换回旧账号 |
| 共享 TModal 改动影响其它 modal | 逐一审计 TModal 使用方 + 加样式断言测试 |

回滚：四个 feature 分支彼此独立，任一分支可单独 revert；epic 分支为聚合，未合并前不影响 `main`。

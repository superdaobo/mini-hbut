# 15 · 教师端页面设计规格：接口 × 数据形态 × 视觉呈现

> 只覆盖**教师端**。所有接口均为 2026-11-20 真实教师账号实测可用（617 条记录）。
> 设计目标：**字少、一眼懂、操作少**。凡是能用数字/色块/进度表达的地方，一律不用文字列表。

---

## 零、三条铁律（所有页面共用）

| 铁律 | 做法 | 反例 |
| --- | --- | --- |
| **数字 > 文字** | 关键结论用 28–40px 大数字直接砸在卡片左上，单位用小字 | 「本学期共完成教学工作量 320 课时」 |
| **颜色 > 标签** | 状态只用一个色点/色条：绿=正常、橙=待办、红=异常、灰=已结束 | 「状态：审批中」 |
| **进度 > 百分比** | 用条形/环形填色，百分比只在必要时作为小字附注 | 「出勤率 94.2%」大段文字 |

**操作收敛**：任何页面进第一屏就能看到结论，不需要「点开筛选 → 查询 → 等结果」。筛选控件默认收起，只在顶部放一个胶囊按钮（如「第 12 周 ▾」）。

## 二、课表（我的 / 班级 / 教室）

**接口**

| 用途 | 接口 | 数据形态 |
| --- | --- | --- |
| 我的课表 | `GET /admin/pkgl/pkgljskb/getJskbByXqid` | `id` 为服务端加密 teacherId，**只能从页面 `#teacherId` 抓** |
| 课表数据 | `GET /admin/pkgl/pkgljskb/ajaxJskbList?jsid=<加密id>` | 按小节逐行返回，**`djs=ceil(djc/2)` 是大节号不是连堂数**，跨大节会多行，必须去重合并 |
| 班级课表 | `GET /admin/pkgl/kbcx/bjkb/qryBjxx` | 3315 个班 |
| 教室课表 | `GET /admin/pkgl/pkglcroomkb` | 1741 间 |
| 节次时间 | `GET /admin/pkgl/pkglqxzkb/getJcinfo?xnxq=` | 11 节，第 1 节 **08:20–09:05** |
| 周次 | `POST /admin/system/jxzy/jsxx/getZcByXnxq` | 0–21（0 是预备周，不展示） |
| 某周日期 | `POST /admin/system/jxzy/jsxx/getXqrqxx` | 参数名必须是 **`zcStr`**，传 `zc` 会 500 |

**呈现**：**周网格**（与学生端 `GlobalScheduleView` 完全一致）

- 左侧 40px 时间轴：节次序号（1–11）+ 起始时刻（08:20…）
- 7 日列，今日列整列浅蓝底
- 课程卡：色块底 + 课程名（最多 2 行，9px）+ 教室（8px）
- 顶部一个胶囊「第 12 周 ▾」，点开是周次选择器（1–21 网格，当前周高亮）
- 三个分段控件：**我的课表 / 班级课表 / 教室课表**；后两者点开才出现搜索框

**交互**：横滑切换周次；点课程卡弹半屏详情（课程名/教室/班级/人数/周次范围）。

**为什么不做列表**：教师看课表是「看时间位置」，列表会丢失空间感。

**接口**：`POST /admin/jsd/jxrw/ajaxListJsJxrw`（60+ 字段，最全）

**数据形态**：6 条，每条含课程名 / 学年学期 / 班级 / 学时 / 人数 / 确认状态

**呈现**：**一行一条，不做表格**

## 七、教师工作量（新功能）

**接口**：`GET /twork/jsd/current-user-gzl`（同 host 微服务，`{code:1,message,data}`，**只接 GET**）

**数据形态**：本学期课时总数、课程数、班级数、学生数

**呈现**：**一个主数字 + 三个副数字 + 周分布条形**

```
┌──────────────────────────────┐
│ 本学期工作量                  │
│      320                      │  ← 48px 超大数字 + 「课时」小字
│      课时 · 6 门课 · 4 个班    │
├──────────────────────────────┤
│ 每周分布                      │
│  ▁ ▃ ▅ ▇ ▇ ▅ ▃ ▁ ▂ ▄ ▆ ▄    │  ← 12 周迷你柱状图（无坐标轴）
│  1  2  3  4  5  6  7  8 …    │
├──────────────────────────────┤
│ 课程明细                      │
│ 计算机制图与表达-1      32 课时│
│ 建筑数字化设计方法      48 课时│
└──────────────────────────────┘
```

**关键决策**：不用表格，用**迷你柱状图**表达「哪几周最累」——这是教师真正想知道的。

**接口异常态**：该教师本学期 `data` 可能为 `null`，此时显示「本学期数据未生成」+ 三个灰占位数字，**不显示 0**（0 会被误读为「没上课」）。

| 网费 | `POST /server/utilities/typeList` | 仅 `broadband` 已绑 |

> **必须 POST JSON**：GET 返回 `{"success":false,"message":"??"}`，不是 405。

**呈现**

```
┌──────────────────────────────┐
│ 补助钱包              2629.42 │  ← 32px 黑，主视觉
│ 主账户 0.00 · 校园卡未领取     │  ← 11px 灰
├──────────────────────────────┤
│ 最近消费                      │
│ 🛒 西苑一层-超市      -12.50  │  ← 图标 + 商户 + 金额
│ 🍚 楚风苑二层-自选餐   -8.00  │
│ 💰 补助入账          +500.00  │  ← 正数绿色
├──────────────────────────────┤
│ [校园码]  网费缴纳             │
└──────────────────────────────┘
```

**关键决策**：
- 余额主视觉给**补助钱包**，主账户降级为灰色小字
- 流水只显示最近 5 笔，点「全部」才进列表（避免首屏滚长）
- 教师无实体卡 → **隐藏挂失/补卡入口**；水电未绑定 → 只显示网费

# 16 · 两端都没有的页面：详细设计

> **判定标准**：`app/viewRegistry.ts` 现有 54 个视图里，学生端和教师端**都没有**这个页面。
> 学生端首页、我的课表、全校课表、空教室、校历、一码通、学习通课程 —— 这些教师端直接复用填数据即可，**不在本文范围**。
> 本文只写 12 个真空白页面。所有接口均为 2026-11-20 真实教师账号实测。

---

## 总览

| # | 页面 | 为什么两端都没有 | 接口可用性 |
| --- | --- | --- | --- |
| 1 | 班级课表 | 学生端只有「我的课表」，全校课表是查询式 | ✅ JSON |
| 2 | 教室课表 | 完全没有 | ✅ JSON |
| 3 | 学生考勤统计 | 学生端无考勤页 | ⚠️ HTML 解析 |
| 4 | 教师端工作量 | 教师专属 | ✅ JSON（微服务） |
| 5 | 学生信息查询 | 学生端 `studentinfo` 查的是自己 | ✅ JSON |
| 6 | 成绩录入进度 | 学生端 `grades` 查的是自己 | ✅ JSON |
| 7 | 学分统计（班级视角） | 学生端 `academic` 看自己 | ✅ JSON |

# 1. 班级课表

**定位**：教师查「任意班级这一周上什么课」。教师最常被问的就是「这节哪个班在上」。

**接口**

| 用途 | 接口 | 数据 |
| --- | --- | --- |
| 班级列表 | `GET /admin/pkgl/kbcx/bjkb/qryBjxx` | 3315 个班（随学期变） |
| 班级课表 | `GET /admin/pkgl/kbcx/bjkb/ckbjkb` | 按 `bjid` + 周次返回 |
| 周次 | `POST /admin/system/jxzy/jsxx/getZcByXnxq` | 0–21 |
| 节次时间 | `GET /admin/pkgl/pkglqxzkb/getJcinfo?xnxq=` | 11 节真实时刻 |

**布局**

```
┌────────────────────────────────┐
│ ‹  班级课表           第 12 周 ▾ │
├────────────────────────────────┤
│ 🔍 输入班级名 / 班级编号         │
│ [25建筑学2班] [25建筑学1班] …    │  ← 最近 3 个班级，横滑
├────────────────────────────────┤
│  11月 16  17  18  19  20  21  22│
│  周    一   二   三   四   五   六   日│
│ 1      ┌────┐                  │
│ 08:20  │建筑│          ┌────┐  │  ← 课程色块，与我的课表同一套配色
│ 2      │数字│          │计算│  │
│ 09:10  └────┘          │机制│  │
│ 3                      │图  │  │
│ 10:15                  └────┘  │
├────────────────────────────────┤
│ 本周 6 节 · 4 门课 · 61 人       │  ← 底部一句话统计
└────────────────────────────────┘
```

**关键视觉规格**

| 元素 | 规格 |
| --- | --- |
| 网格 | 与学生端 `GlobalScheduleView` **完全一致**（40px 时间轴 + 7 日列 + 今日列浅蓝底） |
| 课程块 | 12px 圆角，课程色板同学生端（湖蓝/紫藤/青绿/琥珀/珊瑚），课程名 9px 两行截断 |
| 搜索框 | 只在点「切换班级」后出现，默认收起（避免首屏被键盘占位） |
| 周次胶囊 | 右上角，点击展开 1–21 网格选择器，当前周主色实心 |

**交互**

1. 进页面默认显示**当前教师最近查看的班级**（本地记住），首次进入显示「请选择班级」空态
2. 搜索输入 300ms 防抖，结果以胶囊形式横向排列，点选即切换
3. 左右滑动切换周次（与我的课表同一手势）

**脑洞：冲突提示**

如果查的班级课表里，某节课**正好是教师自己也在上的班**，那个课程块右上角加一个橙色小圆点 —— 教师一眼知道「这个时间我也在这个班」。

**空态**：`{results:[], total:0}` 时显示「该班级本周无课程」，**不要**显示空白网格。

**定位**：教师查「某间教室这周被谁占了」。常用于找空教室、换教室、确认场地。

**接口**

| --- | --- | --- |

```
├────────────────────────────────┤

│ │ 3号-305        本周 18 节课 │ │  ← 教室卡：大字楼栋+教室号
│ │ 容量 60 · 多媒体 · 本部      │ │
│ └────────────────────────────┘ │
│                                │

│ 2 └───┘      └───┘            │

│          │数字│                │
│ …                             │

│ 现在空闲 · 下一节 14:00 有课    │  ← 实时状态条（关键）
└────────────────────────────────┘
```

**关键视觉规格**

| 元素 | 规格 |
| --- | --- |
| 网格 | **5 列**（只显示工作日，周末折叠进「更多」）—— 教室查询场景几乎不关心周末 |
| 教室卡 | 大数字教室号 22px，容量/类型 11px 灰 |
| 状态条 | 固定在底部：绿色「现在空闲」/ 蓝色「正在上课 · 还有 32 分钟」/ 灰色「今日无课」 |

**脑洞：现在空闲 / 还有多久下课**

底部状态条按当前时间实时计算：

- 当前时间落在某节课内 → 「正在上课 · 建筑数字化设计方法 · 还有 32 分钟」
- 当前时间在两节课之间 → 「空闲 · 下一节 14:00 有课」
- 今天没课 → 「今日无课 · 明天 08:20 有课」

这个判断**纯客户端算**（用 `getJcinfo` 的 11 节真实时刻 + 课表数据），不需要额外接口。

**交互**：点任意课程块 → 显示该节课的班级 + 教师（如果接口返回）。

# 3. 学生考勤统计

**定位**：教师看「我带的班出勤怎么样、谁老不来」。

**接口**

| 用途 | 接口 | 数据 |
| --- | --- | --- |
| 考勤页 | `GET /admin/jsd/xskq` | 服务端渲染 HTML |
| 班级/课程维度 | 页面内子查询（需从 HTML 提取表格） | 出勤率、点名次数 |

> ⚠️ 该页无干净 JSON，需解析 HTML。若解析成本过高，**建议整页 WebView 内嵌**，只做外层壳。

**布局**

```
┌────────────────────────────────┐
│ ‹  学生考勤                     │
├────────────────────────────────┤
│ 本学期出勤                      │
│ 94.2 %                          │  ← 40px 大数字
│ 3 个班 · 14 次点名               │
├────────────────────────────────┤
│ 计算机制图与表达-1        94.2% │
│ ████████████████████░           │  ← 条形：>95 绿 / 90-95 蓝 / <90 红
│ 61人 · 14次                      │
│ 建筑数字化设计方法        91.5% │
│ ██████████████████░░            │
├────────────────────────────────┤
│ 点名热力              [12 周 ▾] │  ← 新增：周 × 班 热力矩阵
│       1  2  3  4  5  6  7  8 …  │
│ 计图  ▓ ▓ ▓ ░ ▓ ▓ ▓ ▓           │  ← 越绿越齐，越红缺勤越多
│ 建筑  ▓ ▓ ░ ░ ▓ ▓ ▓ ▓           │
├────────────────────────────────┤
│ 需要关注                   3 人 ›│  ← 折叠
└────────────────────────────────┘
```

**关键视觉规格**

| 元素 | 规格 |
| --- | --- |
| 总出勤 | 40px 800 字重，`%` 用 13px 灰 |
| 进度条 | 高 6px，圆角 3px，底色 `#E5E7EB`，填色按阈值变色 |
| 热力矩阵 | 每格 10×10px 圆角 2px，5 档色阶（`#ECFDF5` → `#065F46`） |
| 异常名单 | 默认折叠成一行，点开才展开；姓名脱敏「张 *」 |

**脑洞：点名热力矩阵**

用「班级 × 周次」的方格矩阵，颜色深浅表示该周出勤率。教师扫一眼就知道：

- 某班从第 6 周开始变红 → 那周开始有人逃课
- 某班整体偏黄 → 全班到课率都不高

这比「94.2%」这个数字有用得多，因为它能定位到**哪一周出问题**。

**交互**：点热力格 → 弹出该周该班的具体点名记录。

# 4. 教师端工作量

**定位**：教师最关心的数字 —— 「我这学期上了多少课」。

**接口**

| 用途 | 接口 | 数据 |
| --- | --- | --- |
| 工作量汇总 | `GET /twork/jsd/current-user-gzl` | `{code:1, message, data}` |
| 明细 | 同微服务 `/twork/*` | 按课程/周 |

> **微服务特性**：同 host 但路径不带 `/admin`；`code:1` 才是成功（不是 `ret:0`）；**只接 GET**，`POST /twork/jsd/search` 返回「数据异常」。

**布局**

```
┌────────────────────────────────┐
│ ‹  教师工作量                    │
├────────────────────────────────┤
│ 本学期                          │
│ 320 课时                        │  ← 52px 超大数字
│ 6 门课 · 4 个班 · 187 名学生     │
├────────────────────────────────┤
│ 每周课时                        │
│  ▁ ▃ ▅ ▇ ▇ ▅ ▃ ▁ ▂ ▄ ▆ ▄       │  ← 12 周迷你柱，高峰周主色
│  1  2  3  4  5  6  7  8 …       │
│            ↑                    │
│        第 5 周最忙 24 课时       │  ← 自动标注峰值
├────────────────────────────────┤
│ 课程明细                        │
│ 计算机制图与表达-1       32 课时 │
│ 建筑数字化设计方法       48 课时 │
│ 湖工大教发培训           24 课时 │
├────────────────────────────────┤
│ 折合系数说明                    │
│ 理论 1.0 · 实践 0.8 · 双语 1.2  │  ← 折叠，默认收起
└────────────────────────────────┘
```

**关键视觉规格**

| 元素 | 规格 |
| --- | --- |
| 主数字 | 52px / 800 字重 / letter-spacing -2px，单位「课时」14px 灰 |
| 迷你柱 | 高 54px，柱宽自适应，圆角 3px 上沿，峰值周 `#2563EB` 其余 `#DBEAFE` |
| 峰值标注 | 小三角 + 「第 5 周最忙 24 课时」11px 灰 |

**脑洞：自动标注最忙一周**

12 根柱子里最高那根下面自动加三角标注。教师不需要数格子就知道「哪周最累」。

**异常态**：`data` 为 `null`（本学期未生成）时，主数字显示 **`—`** 而不是 `0`，副标「本学期数据尚未生成」。0 会被误读为「没上课」。

## 共同的设计约束

1. **不新造视觉语言**：所有页面复用学生端的卡片（18px 圆角）、宫格（48px 实色块）、进度条、色板
2. **不写解释文字**：状态用颜色、结论用数字、进度用图形
3. **空态压成一行**：多项同时为空时用一句话总结，不堆空表格
4. **写型接口一律不接**：`07-write-endpoints-denylist.md` 是红线
5. **个人数据不落盘**：学生信息、成绩明细不写本地缓存

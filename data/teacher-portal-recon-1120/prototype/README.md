# mini-hbut 教师端 · HTML 高保真原型（第三版）

单文件原型：`index.html`（约 560 行，内联 CSS/JS，**零外链**，离线可直接双击打开）。
视口按 375×812 移动端设计，底部 **4 Tab**：首页 / 课表 / 通知 / 我的。

> 第三版信息架构调整：**「教学」Tab 撤销**，其全部功能并入首页，按学生端
> `dashboard_modules.ts` 的 `MODULE_CATEGORY_DEFS` 四分类（教务 / 学习通 / 一码通 / 资源）
> 以宫格形式陈列全部功能入口。
> 前两版教训仍遵守：零外链、页面上不出现任何接口标注、卡片 18px 圆角、单层克制阴影。
>
> **宫格严格照抄学生端**（`templates/views/Dashboard.html:324-359`）：
> 分类 Tab 横向切换（不是全部平铺）+ 4 列宫格 + **48px 实色圆角块 + 白色图标 + 12px 灰字**。
> 教师专属配色沿用 `useTeacherHome.ts` 的 `TEACHER_MODULE_ICON_COLORS`
> （我的教学 `#667eea` / 考试监考 `#38b2ac` / 教务通知 `#6366f1`），其余复用学生端 `FEATURE_ICON_COLORS`。

## 四、真实数据形态（不是假数据）

- 课程：计算机制图与表达-1 / 建筑数字化设计方法 / 数字化创新设计表达2 / 建筑几何编程（双语）/ 详细规划设计 / 湖工大教发培训
- 楼栋：1号 / 2号 / 3号 / 5号 / 7号 / 工1（教师空教室资源域实测只有这 6 栋）
- 节次：11 节，第 1 节 **08:20–09:05**（学校真实时刻，不是 08:00）
- 周次：1–21（`getZcByXnxq` 实测集合，`0` 为预备周且会被服务端当「不过滤」，故不展示）
- 班级人数：739 / 231 / 61 / 81 / 1546（`backclazzdata` 实测）
- 一码通余额：主账户 `0.00` + 补助钱包 `2629.42`（`accTypes` 聚合结果）
- 无任何真实姓名、工号、学号

## 五、空态与异常态（原型已覆盖 5 处）

1. 工作流「待办」为空（`total:0`）
2. 缓考 / 评教本学期未开放
3. 工作量 `current-user-gzl` 本学期返回 null → 结构示意
4. 学习通课程管理「该身份无权限进入管理页面」
5. 门户通知为空（`userNotify/getNewsNotify` 返回空数组）

## 七、本原型不承担的事

- 不接真实接口（纯静态数据，未接入的宫格项一律 toast 占位）
- 不写 Vue/Rust 业务代码，不改 `apps/` 下任何文件
- 不包含写操作入口（无提交申请、无批改、无签到发起、无付款码）

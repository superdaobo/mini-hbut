# 隐私方案（Epic #1243 · G3-05 / mini-hbut#1258）

> 状态：设计定稿（2026-11-13）。**法律/商店审查未做 → BLOCKED**。

## 1. 默认上云的数据类别

| 域 | 默认上云 | 用途 | 第三方可读（需学生逐域同意） |
|---|---|---|---|
| `profile` 基本资料 | ✅ | 身份展示、应用识别学生 | ✅ |
| `schedule` 课表 | ✅ | 课表/提醒/第三方学习应用 | ✅ |
| `grades` 成绩 | ✅ | 成绩查询、趋势、第三方分析 | ✅ |
| `exams` 考试 | ✅ | 考试倒计时/提醒 | ✅ |
| `rank` 排名 | ✅ | 排名展示 | ✅ |
| `cloud_sync` 同步元数据 | ✅ | 设备间一致性 | ❌（第三方不可读） |
| `forum` / `game` | ❌ | 社团/游戏模块自有数据 | ❌ |

**不做的事**：不上云密码、不上云 Cookie、不上云设备私钥、不上云任何凭据。
云端只有「结构化学业数据 + 同步元数据」。

## 2. 留存

| 数据 | 留存 | 删除路径 |
|---|---|---|
| 域快照（`student_cloud_domains`） | 持续保留，每次同步覆盖；**不按数据年龄删除** | 学生「删除云端数据」→ 域级墓碑（`deleted_at`），对象级墓碑按 `event_id` |
| 同意记录（`mini_hbut_app_data_consents`） | 保留（撤销记 `revoked_at`，不物理删，便于审计） | 学生撤销 → 状态置 `revoked` |
| 一次性启动票据 | **内存，60 秒后自然消失** | 消费即删 |
| 审计日志 | 见 §6 | 不含学号原文/令牌 |

## 3. 加密

- **传输**：全链路 HTTPS；第三方只能走 `/api/app-data/v1/*`（不允许自行请求学校教务）。
- **静态**：依赖数据库磁盘加密（部署侧责任）；**应用层不额外加密**（明确记录为已知限制：
  有数据库直读权限者可读明文，需靠 DB 层权限与磁盘加密控制）。
- **令牌**：JWT 由 Casdoor 签发；OCR 侧只做 JWKS 验签，**不存储令牌**。
- **票据**：`token_urlsafe(32)`，只在内存，不落盘、不写日志。

## 4. 导出与删除

| 操作 | 入口 | 行为 |
|---|---|---|
| 导出 | 「我的数据 → 导出」 | 导出该学生全部域快照 + 同意记录（JSON），**不含凭据** |
| 删除云端数据 | 「删除云端数据」 | 写域级墓碑；本地数据保留（用户可选择同时清本地） |
| 删除账号 | 账号注销 | 域快照 + 同意记录 + 设备登记一并清除（级联） |

> 导出/删除的 UI 与后端端点**尚未实现**（T13/T15 范围外），本文件定义的是契约。

## 5. 旧「关闭同步」用户的迁移告知（`hbu_cloud_sync_user_disabled`）

现状：历史版本有「关闭云同步」开关，用户可能已关闭。

Epic 决策：**云同步改为常驻基础能力**（不再提供关闭）。迁移要求：

1. **不静默上传**：首次启动检测到旧偏好为 `disabled` 时，**先展示告知页**：
   「云同步已成为基础能力，用于多设备一致与第三方应用读取；继续即表示同意，你也可以先导出/删除云端数据。」
2. 用户选择「暂不」→ 本次会话不上传（**保留本地可用**），下次启动再提示。
3. 用户选择「继续」→ 清除旧偏好键，进入常驻同步。
4. **实现状态：未做**（需 UI + 一次性标记；记入 T15/T16 遗留）。

## 6. 第三方历史副本治理

问题：学生撤销授权后，第三方可能已缓存数据。

| 措施 | 状态 |
|---|---|
| 响应带 `meta.last_synced_at`，让第三方能自证数据来源时间 | ✅ 已实现（OCR#57） |
| 撤销后**服务端立即 403**（同一令牌） | ✅ 已实现 + 测试 |
| 接入协议要求「撤销后停止使用并删除缓存」 | ✅ 已写入接入示例（#1282） |
| **技术强制第三方删除历史副本** | ❌ 不可能（数据已出域）；只能靠协议 + 审计 |
| 定期审计第三方访问日志 | ⏳ 未做（需运维流程） |

**诚实结论**：撤销能保证「以后读不到」，**不能**保证「已经拿走的被删掉」。这一点必须在隐私说明里写明，不能给用户「撤销=彻底删除」的错觉。

## 7. 使用统计独立

使用统计（匿名埋点）与学业数据**完全独立**：

- 不进入任何云快照域；
- 不随第三方 API 暴露；
- 单独开关（默认开，可关），关闭不影响云同步与第三方读取。

**实现状态：未做**（需埋点基建；记入遗留）。
